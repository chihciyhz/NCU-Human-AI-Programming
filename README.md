## 五、给零基础者的 Git 三板斧

每次写完作业想存一版，在仓库目录下依次执行：

```bash
git add .                              # 1. 把改动放进"待寄包裹"
git commit -m "week01: 完成环境搭建"    # 2. 打包并贴上说明标签
git push                               # 3. 推送到 GitHub
```
